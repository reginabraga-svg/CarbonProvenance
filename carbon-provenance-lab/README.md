# Carbon inventory evaluation dashboard

Hosted inspection site:
https://carbon-provenance-lab-20261116.reginambvillela.chatgpt.site

Run the server in the sibling carbon-audit directory to execute plans. The hosted interface does not require a Python installation for inspection.
The interface presents S1 outputs, behavior tests, NOAA transfer records and a demonstration plan. Each record identifies its source. Evaluation results include the controlled withdrawal of a NOAA input.
JSON exports retain evidence, plans and results. The evaluation workspace imports those files. Execution requires access to the local server on the same origin.
Article figures 4 and 5 use the plotting function in dist/charts.js. See carbon-audit/CHARTS.md for reproduction commands.
